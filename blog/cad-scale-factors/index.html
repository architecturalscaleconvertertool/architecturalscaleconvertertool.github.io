CAD Scale Factors: Chart, Viewport XP Values, and Text/DIMSCALE Settings

Published October 20, 2026 · 5 min read

CAD scale factors connect a full-size model to its plotted size. Use the charts below to find the factor for an architectural or engineering drawing, enter its reciprocal as a viewport XP value, and size non-annotative text and dimensions for the plot.

Unit assumption: model space and paper space both use inches throughout these charts and examples. Manual annotation scaling applies to non-annotative objects. Annotative text and dimensions use annotation scales instead; do not multiply their sizes again.

What Is a CAD Scale Factor?

A CAD scale factor tells you how many full-size drawing units correspond to one plotted unit when both use the same units. For a drawing at 1/4" = 1'-0", divide 12 inches by 1/4 inch: the factor is 48.

Keep the factor and the display ratio separate. The factor is 48, while the paper-to-model ratio is 1:48. AutoCAD uses the reciprocal, 1/48xp, to display that reduction in a layout viewport. Entering 48xp would enlarge the view instead.

How to Set Viewport Scale with XP

To set the viewport scale factor in AutoCAD, activate the layout viewport, run ZOOM, and enter the reciprocal factor followed by xp.

  1. In paper space, double-click inside the viewport to enter model space through it.
  2. Type Z and press Enter to run ZOOM.
  3. Enter the XP value from the chart. For 1/8" = 1'-0", enter 1/96xp with model and paper units both in inches.

The XP suffix makes the zoom value relative to paper-space units. For example,.5xp displays the model at half size; it is not the same as 1/2" = 1'-0", which needs 1/24xp under these unit assumptions.

Lock the viewport scale after setting it. Stretching its border changes the visible area, not the scale of the view inside it.

How to Apply AutoCAD Scale Factors

For non-annotative model-space text, multiply the desired plotted height by the drawing factor. Other settings depend on the object and plotting workflow:

  • Text, attributes, and table text: desired plotted height × factor = model-space height.
  • Dimensions: for traditional non-annotative model-space plotting, use the factor as DIMSCALE. Layout-based and annotative methods differ, as explained below.
  • Linetypes: choose LTSCALE with the linetype definition and intended dash length in mind. It is not automatically equal to the drawing factor.
  • Hatches: set hatch scale for the chosen pattern. Architectural patterns with the AR prefix commonly use the drawing factor.
  • Blocks: geometry is usually drawn full size. Text or attributes within a block may need annotation scaling; do not resize full-size geometry merely to make its text readable.

Dimensioning in Model Space and Paper Space

Model-space plotting uses a manual dimension scale in the traditional workflow; layout-based dimensioning can account for viewport scale automatically. Choose the method before setting DIMSCALE.

  1. Dimension in model space for model-space plotting. Set DIMSCALE to the inverse of the intended plot scale. A plot scale of 1/4 needs DIMSCALE = 4. This 1:4 ratio differs from the architectural notation 1/4" = 1'-0", which is 1:48.
  2. Dimension in model space for paper-space plotting. In the non-annotative layout-scaling method, set DIMSCALE to 0 to scale dimensions for display in a layout viewport. Separate dimension layers can keep dimensions for one viewport hidden in the others.
  3. Dimension in paper space. Associative dimensions attached to model-space objects account for the viewport's display scale together with DIMLFAC. Nonassociative dimensions need DIMLFAC set manually.

For annotative dimension styles, DIMSCALE is 0 and the annotation scale controls sizing. Do not apply the manual text-height multiplication to annotative dimensions.

CAD Scale Factor Example for 1/4" = 1'-0"

A floor plan at 1/4" = 1'-0" uses a factor of 48 and a viewport value of 1/48xp when model and paper units are inches. For non-annotative model-space annotation:

  • Factor: 12 ÷ 1/4 = 48.
  • Viewport zoom: 1/48xp.
  • Text intended to plot 1/4" high: 1/4 × 48 = 12" in model space.
  • DIMSCALE for the traditional model-space plotting method: 48.

Check the result in reverse: 12" of model-space text height × 1/48 = 1/4" on paper. This reciprocal check helps catch a factor entered the wrong way around.

How to Add a Custom Drawing Scale

Use SCALELISTEDIT to add a custom scale to the drawing's scale list. It changes the available scale choices without resizing the model geometry.

To bring changes from the default scale list into the current drawing, use Reset in the Edit Drawing Scales dialog. Scales stored in a template carry into new drawings created from it; user-profile scales are not imported automatically.

For repeat projects, keep the required CAD scale factors in the drawing template so the scale choices are available from the start.
